# Slides for TPP2026

[TPP2026](https://auto-res.github.io/tpp2026/ja/) にて **「AI援用による数理論理学の形式化と未解決問題集の作成に関する報告」** という題で発表した際のスライドです．

最新のPDFファイルが https://sno2wman.github.io/slides-for-TPP2026/main.pdf から入手出来ます．

## ビルド

Typst 0.15.1 でビルドする．使うフォントは Newsreader，Geist，Juisee，Material Symbols Outlined で，取得元は [deploy.yml](.github/workflows/deploy.yml) を参照．

```bash
typst compile main.typ
```
